# PONG-84

经典的打砖墙风格的 PONG 游戏变体，采用 ASCII 字符渲染，带 CRT 复古风格界面，支持单人与双人对战。

- 纯 HTML / CSS / JavaScript，零依赖
- 直接在浏览器中打开 `index.html` 即可游玩
- 键盘操作，支持玩家增强选项

## 玩法

- 单人模式：操控球拍反弹小球，防止球越过底线
- 双人模式：两名玩家各控一侧球拍对战

## 使用

```bash
git clone https://github.com/chorusfruit-233/PONG-84.git
cd PONG-84
# 用浏览器打开 index.html
```
