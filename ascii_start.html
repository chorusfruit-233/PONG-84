高级设置 · STUN / TURN / 信令

通常可先使用默认设置。变更仅在新连接生效；设置只保留在当前标签页。











TURN 凭据不会写入本地存储、连接码或导出文件。不要将长期凭据或服务商 API 密钥写进公开 HTML。


以下仅影响“云端联机”，手动连接不使用信令服务

双方打开本文件，选择相同的网络范围。无需摄像头或麦克风权限。




































连接码较长，不是 4 位房间码；只发给本次对手。生成后保持双方页面打开。关闭、刷新或重新生成后，旧连接码失效。






自动交换信令，需外部 PeerJS 组件与信令服务。4 位码不是密码；双方需使用同一服务、分组和本版本。
























连接诊断 / 联机失败怎么办



同一 Wi-Fi 也可能有设备隔离、防火墙或浏览器策略限制。跨网络配置 STUN 仍失败时，需有效 TURN 中继；换成 GitHub Pages 本身不会解决穿透问题。


“无外部服务”仅指手动连接 + 同一局域网。两台设备没有任何可达网络时，不能隔空联机。手机请用完整浏览器打开，勿使用聊天软件中的 HTML 预览。

渲染方式
ASCII 是独立文本路径，不创建 Canvas / WebGL / WebGPU；图形模式独立使用高清画布与光影效果。

        
ASCII 性能档位
自适应优先 60 帧，持续负载高时降低字符密度与刷新率；不改球速、判定或键盘移速。再次选择“自适应”可重试高档。

        
图形画质
精致光影：光学玻璃球场、金属导光球拍、动态光照反射、连续能量尾迹与分层碰撞光效。均衡档减少像素与粒子数量；不受 ASCII 节能设置限制。
